# Private street-car source candidates

Sixteen complete user-downloaded road-car archives are stored here for Claude's import queue.
They are source packages only, not selectable cars and not traffic-ready assets.

The archives contained no license or attribution documents. Keep this repository private,
identify the source and license for each package before redistribution, reject game-ripped
models, and remove or replace protected branding for any released build.

For each car, Claude still needs to inspect the archive, select the best source format, preserve
the interior, separate the wheel assemblies, fit the driver/camera, create collision and LODs,
register the vehicle, tune it from researched specifications, and run the asset and driving
tests. `../USER_CAR_BATCH_MANIFEST.tsv` is the authoritative inventory.
