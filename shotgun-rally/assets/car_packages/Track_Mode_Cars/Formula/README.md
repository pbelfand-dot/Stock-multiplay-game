# Formula source candidates

Two modern, fictional open-wheel cars for the FORMULA class:

| File | Description | Source | License |
|---|---|---|---|
| `current-ground-effect-racer.glb` | Current-era ground-effect single-seater; named wheel pivots and `wheel-roll` animation | [3DAssets.dev asset 15179](https://3dassets.dev/assets/grand-prix-circuit-and-open-wheel-ground-effect-racer-02c3b491) | CC0 1.0 Universal |
| `modern-halo-open-wheel-racer.glb` | Modern single-seater with halo, exposed suspension and multi-element aero; named wheel material/pivot hierarchy and `wheel-roll` animation | [3DAssets.dev asset 18685](https://3dassets.dev/assets/transport-collection-hd-open-wheel-racer-aa0e5cef) | CC0 1.0 Universal |

Both are original generic designs with no real team or sponsor branding. Both were generated
with AI tools by the upstream contributor (Claude Fable 5.1); neither page carries a `No AI`
restriction. The source GLBs are static vehicle geometry with rigid-node wheel animation, not
finished driving rigs, physics, collision, or player-fit implementations.

`upstream-pack-manifest.json` and `modern-halo-open-wheel-racer.source.json` preserve the
machine-readable upstream descriptions, dimensions, geometry counts, license, and CDN URLs.

## Private branded source candidates
