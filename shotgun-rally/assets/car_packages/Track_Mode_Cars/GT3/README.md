# Generic GT race-car source candidates

Four original, fictional closed-cockpit race cars for a varied GT grid:

| File | Description | Source | License |
|---|---|---|---|
| `front-engine-gt-race-coupe.glb` | Front-engine GT race coupe | [3DAssets.dev asset 14834](https://3dassets.dev/assets/endurance-and-gt-paddock-front-engine-gt-coupe-ff0949d7) | CC0 1.0 Universal |
| `mid-engine-gt-race-coupe.glb` | Mid-engine GT race coupe | [3DAssets.dev asset 14833](https://3dassets.dev/assets/endurance-and-gt-paddock-mid-engine-gt-coupe-0cbb6f3a) | CC0 1.0 Universal |
| `gt4-sports-coupe.glb` | GT4-style sports coupe suitable for a lower-power class or AI visual variant | [3DAssets.dev asset 14838](https://3dassets.dev/assets/endurance-and-gt-paddock-gt4-sports-car-69ecfad1) | CC0 1.0 Universal |
| `one-make-cup-coupe.glb` | Compact one-make cup racer suitable for an AI visual variant | [3DAssets.dev asset 14847](https://3dassets.dev/assets/endurance-and-gt-paddock-cup-coupe-89cf3ec5) | CC0 1.0 Universal |

All four provide named wheel/door/bonnet pivots and rigid-node `wheel-roll`, `doors-open`, and
`bonnet-open` clips. They are original generic designs, not branded Ferrari/BMW/Lamborghini/
Audi/McLaren/Aston/Ford/Corvette replicas. All were generated with AI tools by the upstream
contributor (Claude Fable 5.1); none carries a `No AI` restriction.

`upstream-pack-manifest.json` preserves the machine-readable upstream record. These files are
source candidates and still need vehicle registration, physics, collision, cockpit/player-fit,
LOD, audio, and multiplayer work before they are playable.

## Private branded source candidates

Seven user-downloaded circuit-car archives are stored here. They contained no license or
attribution documents and are pending provenance review. Three archives over 100 MB are split
into ordered `.parts` directories; `USER_CAR_BATCH_MANIFEST.tsv` records the original hashes.
Do not redistribute these packages or call them game-ready until their provenance and full
vehicle integration have both been verified.
